# Лабораторная №1. Основы Go

## Задача

Лабораторная реализует небольшой консольный каталог книг. Программа создаёт книги, выводит их, выполняет поиск по автору, считает доступные экземпляры, определяет самую новую книгу и группирует каталог по авторам.

Цель работы — познакомиться с базовым синтаксисом Go: структурами, методами, указателями, слайсами, `map`, циклами и несколькими возвращаемыми значениями.

## Запуск

Из корня репозитория:

```bash
go run ./lab01-basics
go test ./lab01-basics
```

Из каталога лабораторной:

```bash
go run .
go test .
```

## Сравнение с Java

| Go | Приблизительный аналог в Java | Главное отличие |
|---|---|---|
| `struct` | Класс с полями | У структуры Go нет наследования и конструкторов языка |
| Функция `NewBook` | Конструктор или статический factory method | Это обычная функция, а не специальная конструкция языка |
| Method receiver | Метод экземпляра | Receiver записывается перед именем метода |
| `[]Book` | `ArrayList<Book>` | Slice — представление последовательности поверх массива |
| `map[string][]Book` | `HashMap<String, List<Book>>` | `map` — встроенный тип языка |
| Pointer receiver `*Book` | Изменение состояния Java-объекта | В Go явно указано, что метод работает с адресом исходного значения |

## Основные отличия от Java

- В Go нет классов: данные обычно описываются структурами.
- Конструктор `NewBook` является обычной функцией и вызывается явно.
- Методы можно объявлять как для значения `Book`, так и для указателя `*Book`.
- Ошибку отсутствия результата часто показывают дополнительным значением `bool`. Поэтому `FindNewestBook` возвращает `(Book, bool)`.
- Цикл `for` используется и как обычный цикл, и как аналог Java `for-each`.
- `range` возвращает индекс и значение. Ненужный индекс можно пропустить через `_`.
- Слайс может увеличиваться с помощью встроенной функции `append`.
- Порядок обхода `map` не гарантируется.
