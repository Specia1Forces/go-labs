# Go Labs

Учебный репозиторий с самостоятельными лабораторными работами по основам Go. Он предназначен для закрепления языка разработчиком, уже знакомым с Java и базовыми принципами backend-разработки.

## Лабораторные работы

| № | Каталог | Темы |
|---|---|---|
| 1 | `lab01-basics` | Синтаксис Go, основные типы, функции, структуры, методы, слайсы и map |
| 2 | `lab02-interfaces-errors` | Интерфейсы, явный возврат ошибок, оборачивание и проверка ошибок |
| 3 | `lab03-concurrency` | Горутины, каналы, `sync.WaitGroup`, `sync.Mutex` и race detector |
| 4 | `lab04-http-server` | HTTP-сервер на `net/http`, JSON и тестирование обработчиков через `httptest` |

Лабораторные реализованы последовательно. Каждая работа содержит собственное описание, исходный код и тесты.

## Требования

- установленный Go;
- Git для контроля версий;
- сторонние библиотеки не требуются.
